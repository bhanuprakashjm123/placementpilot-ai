# PlacementPilot AI

**Your AI Mentor for Placements**

An AI-powered placement preparation platform helping engineering students go from
placement prep to job offer — combining personalized learning roadmaps, resume
tools, AI mock interviews, and progress tracking.

## Status

🚧 Under active development.

## Tech Stack

- **Frontend**: React, Vite, Tailwind CSS
- **Backend**: Python, FastAPI
- **Database**: PostgreSQL
- **Auth**: JWT (self-managed)
